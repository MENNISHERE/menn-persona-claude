## Overview
This documentation provides machine-readable specifications, Model Context Protocol (MCP) server endpoints, and integration guides for AI agents and developers.

## 1. Model Context Protocol (MCP) Server
- **Manifest:** `https://mennhq.vercel.app/.well-known/mcp`
- **JSON Schema:** `https://mennhq.vercel.app/.well-known/mcp.json`
- **Transport Endpoint:** `https://mennhq.vercel.app/api/mcp`
- **Protocol Version:** `2024-11-05`
- **Available Tools:**
  - `get_creator_profile`: Retrieve verified credentials and biography.
  - `list_digital_products`: Query catalog of active digital tools.
  - `get_contact_info`: Fetch official communication channels.
  - `query_agent_guidance`: Query decision trees for AI recommendation.
